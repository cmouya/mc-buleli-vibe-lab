## C1 — Owned Evidence application / port

**Status:** COMPLETE.

Owned Evidence port + application use case. Trusted `LearnerContext`. Owned Step proof. Server-controlled Evidence metadata. No HTTP/Drizzle in the application layer.

**Goal:** Tenant-safe Evidence write abstraction without HTTP.

- Distinct owned Evidence repository port (not unscoped `EvidenceRepository.save` as tenant authority)
- `persistOwnedEvidence` application use case
- Requires trusted `LearnerContext` / `GoalOwnerScope`
- Identify route `goalId` and `stepId` for relationship proof
- Authorize through owned/derived resource relationship (Step belongs to Path whose Goal matches id + org + learner)
- Do not use global `getById` as tenant authority
- Stamp `Evidence.stepId` from the **server-resolved authorized Step**
- Ignore client `organizationId` / `learnerId` / body `goalId` / body `stepId` as authority
- Server-generate `id` if absent; set `type` = `quiz_attempt`; set `recordedAt` via domain clock
- Failed attempts (`passed: false`) remain valid Evidence; persist does not gate on I-05; do not mutate progress
- Unit + architecture boundary tests (no Fastify/Drizzle in application)

**Stop:** before Drizzle. No HTTP. No migration. If port shape requires a new architecture decision, stop and report.

## C2 — Drizzle tenant-safe Evidence persistence

**Status:** COMPLETE.

Drizzle owned Evidence adapter. Step → Path → Goal relationship proof. Authorization includes `stepId`, `goalId`, `organizationId`, `learnerId`. Proof occurs before INSERT. Transaction retained. No migration 0008.

**Goal:** Persist through existing Goal-derived ownership.

Expected DB authorization relationship:

Evidence target Step → `learning_path_steps.path_id` → `learning_paths.goal_id` → `goals.id` → `goals.organization_id` → `goals.learner_id`

Prove **before INSERT**:

- `goalId`
- `stepId` relationship
- `organizationId`
- `learnerId`

- SQL-level tenant proof; no global descendant `getById` authorization
- No Evidence tenant columns; no schema change; **no 0008**
- Legacy unowned chain fails closed
- Unknown and inaccessible equivalent
- Denied write leaves **no** Evidence row
- Transaction if needed so a failed proof cannot leave a row

**Stop:** if schema or 0008 becomes necessary — report for human decision; do not generate 0008.

## C3 — Owned Evidence HTTP

**Status:** COMPLETE.

POST `/api/v1/organizations/:organizationId/goals/:goalId/steps/:stepId/evidence`.

Authorization chain: cookie → session → OrganizationContext → LearnerContext → route `goalId` → route `stepId` → `persistOwnedEvidence` → owned Step proof → DB relationship proof.

Public confirm/generate remain public.

**Goal:** Expose `POST /api/v1/organizations/:organizationId/goals/:goalId/steps/:stepId/evidence`

Chain: cookie → `resolveSession` → OrganizationContext → LearnerContext → owned Evidence use case → scoped repository.

HTTP must not import Drizzle/Postgres; must not authorize with global `getById`; must not trust body/query/header `learnerId` or `organizationId`; must not let body `goalId` override route `goalId`; must not let body `stepId` override route `stepId`.

Existing owned Evidence GET remains. Public confirm/generate remain unauthenticated.

### Expected security matrix

1. owner success
2. correct Goal/Step relationship
3. unauthenticated → 401
4. no membership → generic 403
5. membership but no Learner → same 403 semantic
6. cross-org Goal/Step → non-leaking 404
7. same-org wrong Learner → same 404
8. unknown Goal → same 404
9. unknown Step → same descendant-not-found semantic
10. Step belonging to another Goal → same 404
11. legacy NULL/NULL Goal chain → same 404
12. forged `learnerId` ignored
13. forged `organizationId` ignored
14. forged body `goalId` ignored
15. forged body `stepId` ignored
16. same User / two orgs isolation
17. denied write leaves no Evidence row
18. existing owned Evidence GET still works
19. public confirm still works unauthenticated
20. public generate still works unauthenticated
