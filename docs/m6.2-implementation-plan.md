## C1 — Owned Path application / port

**Status:** COMPLETE.

**Goal:** Tenant-safe Path write abstraction without HTTP.

- Owned Path repository port (or equivalent) distinct from unscoped `LearningPathRepository`
- `persistOwnedPath` / `acceptOwnedPath` application use case
- Requires trusted `LearnerContext` / `GoalOwnerScope`
- Server-resolved **owned Goal** before persist
- `Path.goalId` stamped from that Goal (not client ownership fields)
- Nested Steps persisted with the Path
- Unit + architecture boundary tests (no Fastify/Drizzle in application)

**Stop:** before Drizzle. No HTTP. No migration. If port shape requires a new architecture decision, stop and report.

## C2 — Drizzle tenant-safe Path persistence

**Status:** COMPLETE.

**Goal:** Persist through existing Goal ownership.

- Prove Goal belongs to `organizationId` + `learnerId` (scoped query, not global `getById`)
- Persist Path + nested Steps under that Goal
- No Path/Step tenant FKs
- Legacy/unowned Goal fails closed
- DB tests: owner success; cross-org; wrong Learner; legacy NULL/NULL
- **No 0008 expected**

**Stop:** if schema or cardinality (UNIQUE goal_id) becomes necessary — report for human decision; do not generate 0008.

## C3 — Owned Path HTTP

**Status:** COMPLETE.

**Goal:** Expose `POST /api/v1/organizations/:organizationId/goals/:goalId/path`

Chain: cookie → `resolveSession` → OrganizationContext → LearnerContext → owned Goal → owned Path use case → scoped repository.

Security matrix:

- owner success
- unauthenticated → 401
- no membership → generic 403
- membership but no Learner → generic 403
- cross-org → generic 404
- same-org wrong Learner → generic 404
- unknown Goal → generic 404
- legacy NULL/NULL Goal → generic 404
- forged learnerId ignored
- forged organizationId outside path ignored
- forged body `goalId` cannot redirect ownership
- same User, two orgs isolated
- unknown vs inaccessible identical body

Public `POST /api/v1/paths/generate` remains 200 without cookie. Existing C7 GET routes remain.
