# M5.2 recorded decisions (human-reviewed)

**Status:** Binding for M5.2 **implementation** (separate coding plan). Do not treat the architecture audit as executable.

**ADR-002** (PostgreSQL) and **ADR-005** (server sessions + HTTP-only cookies) stay **unchanged**. **ADR-014** is **Accepted** in [`docs/architecture-baseline.md`](architecture-baseline.md) §20. Schema/HTTP still wait for a coding session; ADR-014 must precede migration `0005` and auth code.

## Adopted answers

| # | Decision | Answer |
|---|----------|--------|
| 1 | Session token storage | **B.** Cookie = CSPRNG token (32+ bytes, base64url). DB = **SHA-256** `token_hash` UNIQUE. No reusable raw session secret in PostgreSQL. |
| 2 | Active organization | **No `organization_id` on `sessions`.** Memberships loaded by `user_id`. Client `organizationId` is never authority. |
| 3 | Password KDF | **Argon2id approved.** PHC string in `secret_hash`. No pepper. Dummy verify if identifier missing. Rehash-on-login if params stale. **Library not frozen.** Candidates: `@node-rs/argon2` or `argon2`. Choose during M5.2 implementation after Windows/CI compatibility verification. |
| 4 | Cookie | Name **`learnova.sid`**. HttpOnly. SameSite=**Lax**. Path `/`. No Domain. No `__Host-`. Secure in production; **not** Secure on HTTP localhost. |
| 5 | Expiration | **Absolute 24h** (`expires_at` + cookie Max-Age). No sliding/idle in M5.2. |
| 6 | Revocation | **`revoked_at`** (keep row). Logout this session only. Logout-all later. |
| 7 | Registration | **No public register.** In-process `bootstrapTestIdentity` + hasher for tests. |
| 8 | Rate limit | **M5.2 MUST** rate-limit `POST /api/v1/auth/login`. Candidate: **`@fastify/rate-limit`**. In-memory is acceptable for single-instance M5.2. Redis deferred. **Do not defer login rate limiting to M5.3.** |
| 9 | ADR | Additive **ADR-014 Accepted** (baseline §20). Must precede migration `0005` / auth code. Do not edit ADR-002/005 Decision rows. |
| 10 | Slice | **C:** login, logout, GET session. Full tenant-isolation proof = **M5.3**. Confirm/generate stay public. Golden Reference unchanged. No M4 ownership changes. |

JWT as primary auth, Lucia, Redis session/rate-limit store, Learner, M4 ownership columns, persist Goal/Path HTTP, Golden Reference login/dual-write, `GET /organizations/current`, password-reset, CSRF tokens, `__Host-` cookie, logout-all route, full tenant isolation.
