## C1 — Application / domain / port

**Status:** NOT STARTED.

**Goal:** Tenant-safe owned derived Completion/Progress without HTTP.

- Trusted `LearnerContext` / `GoalOwnerScope`
- Requested `goalId`
- Owned Path/Step resolution (existing owned-derived semantics)
- Consume **persisted** owned Evidence (not client-asserted completion)
- Evaluate I-05 (`assertEvidenceAllowsCompletion`: matching `stepId` and `passed`)
- Derived Step completion: ANY authorized persisted Evidence satisfying I-05
- Derived Path: `totalSteps`, `completedSteps` (Steps, not Evidence rows), `progressPercent`
- Zero-step: `totalSteps = 0` → `completedSteps = 0`, `progressPercent = 0`
- Repeated Evidence: failed→passed complete; passed→failed remains complete; multiple passed not “more complete”
- Side-effect free (no mutation of Evidence/Step/Path/Goal/Learner/LearnerState/Skills/Mastery)
- Optional internal owned Evidence-by-Step port; **do not** use unscoped `EvidenceRepository.getByStepId` as tenant authority
- Port naming follows existing owned-* conventions at implementation time; **security semantics are frozen**, exact interface name is not
- Client tenant identifiers never authority; no global `getById` as tenant authority
- Unit + architecture boundary tests (no Fastify/Drizzle in application)

**Stop:** before Drizzle. No HTTP. No migration.

## C2 — Database / relational proof

**Status:** NOT STARTED.

**Goal:** Tenant-safe relational query for derived Completion/Progress. **No writes. No schema change. No 0008.**

Ownership proof:

Path/Step → Goal, with trusted `organizationId` + `learnerId` (and requested `goalId`).

Evidence may contribute only after that proof. Unscoped `getByStepId` is not authority.

Required security cases: valid owner; cross-org Step; wrong Learner same org; wrong Goal; unknown Step; unknown Goal; legacy NULL/NULL Goal; same User / two Organizations; duplicate Evidence; failed-only; passed; mixed failed/passed.

Denied access must not produce scoped data.

**Stop:** if schema or 0008 becomes necessary — report for human decision; do not generate 0008.

DB tests: Learnova PostgreSQL only `postgres://learnova:learnova@localhost:5433/learnova`. Never DocGov360 on 5432.

## C3 — Owned HTTP read

**Status:** NOT STARTED.

**Goal:** Expose `GET /api/v1/organizations/:organizationId/goals/:goalId/path/progress`

Chain: cookie → `resolveSession` → OrganizationContext → LearnerContext → owned Goal/Path/Step → persisted owned Evidence → derived Progress.

Read-only. HTTP must not import Drizzle/Postgres; must not authorize with global `getById` / unscoped `getByStepId`; must not trust body/query/header `learnerId` or `organizationId`.

Do not add Evidence list. Do not add a completion command. Do not mutate Evidence POST.

Public confirm/generate remain unauthenticated.

### Expected security matrix

1. owner success (derived totals / percent)
2. unauthenticated → 401 `AUTH_UNAUTHENTICATED`
3. no membership → generic 403 `ORG_FORBIDDEN`
4. membership but no Learner → same 403 semantic
5. Learner but no membership → same 403 semantic
6. cross-org → non-leaking 404 `RESOURCE_NOT_FOUND`
7. same-org wrong Learner → same 404
8. unknown Goal → same 404
9. inaccessible Path → same 404
10. legacy NULL/NULL Goal chain → same 404
11. forged `learnerId` ignored
12. forged `organizationId` ignored
13. forged query/header tenant fields ignored
14. same User / two orgs isolation
15. GET causes no writes
16. public confirm still works unauthenticated
17. public generate still works unauthenticated
18. Evidence POST semantics unchanged (regression)
