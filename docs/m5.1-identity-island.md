# M5.1 — Identity island

**Status:** **Done.** Persistence only. No HTTP auth.

**Depends on:** [`docs/m5-decisions.md`](m5-decisions.md), ADR-013.

**Did not implement:** HTTP auth, cookies, sessions table, login/logout, persist Goal/Path/Evidence, Learner, Golden Reference changes, M4 ownership FKs.

## Objective

Persist the **identity island**: Organization, User, password-type credential (`secret_hash` opaque), Membership roles `org_admin` | `member`. Multi-org via membership rows. Domain/application remain Drizzle-free.

This is **not** tenant isolation over HTTP (M5.3) and **not** ADR-005 sessions (M5.2).

## Tables

- `organizations` — UUID PK, `name`, `created_at`
- `users` — UUID PK, `created_at` (no email, password, org, role)
- `user_credentials` — FK `users` RESTRICT, type CHECK `password`, UNIQUE `(type, identifier)`, `secret_hash`
- `organization_memberships` — FKs RESTRICT, role CHECK (`org_admin`, `member`), UNIQUE `(organization_id, user_id)`

M4 `goals` / `learning_paths` / `learning_path_steps` / `evidence` unchanged.

## Out of scope (still)

- `sessions` table, `@fastify/cookie`, login/logout routes
- `GET /organizations/current`
- Learner, Program, Cohort
- Progress, Mastery, Skill persistence
- Open self-registration HTTP
- JWT
- Editing ADR-002 / ADR-005
