# McBuleli Vibe Lab

Gestionnaire de tâches simple pour un participant à un hackathon.
Interface en français, sans backend : les tâches sont stockées dans le navigateur (`localStorage`).

## Prérequis

- Node.js (LTS) et npm

## Lancer le projet

```bash
npm install
npm run dev
```

L’app s’ouvre en général sur [http://localhost:5173](http://localhost:5173).

## Commandes utiles

```bash
npm run build
npm run preview
```
